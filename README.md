One line roasting a smart fridge: it updated its firmware overnight and now refuses to open until its owner agrees to terms they can't read without opening it. Entry for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
